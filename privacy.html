Jarvis Privacy Policy

Last updated: 26 November 2026

Jarvis is a personal assistant that one person built for their own use. It runs on that person's own computer. It is not a commercial service and has no other users. This policy explains what Jarvis does with Google account data when its owner connects it to Gmail and Google Calendar.

What Google data Jarvis can access

  • Gmail, read only (gmail.readonly): to find and read messages the owner asks about.
  • Gmail, compose (gmail.compose): to write drafts and, only with the owner's approval, send them.
  • Google Calendar events (calendar.events): to read upcoming events and, only with the owner's approval, create new ones.

How the data is used

  • Jarvis uses Google data only to answer the owner's own requests, such as "what's in my inbox" or "book a meeting tomorrow at 3".
  • To summarise or answer questions about emails and events, Jarvis sends the relevant text to the AI model provider it is configured to use. Only the text needed for that request is sent.
  • Jarvis never sends an email or books an event unless the owner says yes out loud and clicks a confirm button on screen.
  • Google data is never used for advertising. It is never sold or shared with anyone else, and it is never used to train AI models.

Where the data is stored

  • The Google sign-in token is kept in a file on the owner's own computer. It is never uploaded anywhere and never shown in a web page.
  • Jarvis does not keep its own copy of the mailbox or calendar. It reads them from Google when asked.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove Jarvis's access at any time at myaccount.google.com/permissions, or by deleting the token file on their computer.

Contact

Questions about this policy can be raised through the Jarvis project on GitHub.
